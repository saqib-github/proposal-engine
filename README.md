# Proposal Engine — AI-Powered Bid & Proposal Response Engine

**CUST Hackathon · Problem #1** · Industry: Procurement, Sourcing & Contract Management

An intelligent assistant for bid & proposal teams that:

- **Ingests** RFP / RFQ / Tender documents (PDF or DOCX) and extracts mandatory requirements, evaluation criteria, submission deadlines, and Q&A sections
- **Matches** extracted requirements against a Company Capability Library (past projects, certifications, CVs, case studies) using RAG
- **Auto-drafts** a structured proposal response with relevant evidence mapped to each section
- **Flags compliance gaps** so bid managers can prioritize effort
- **Scores win probability** (budget alignment, competitor presence, past win rate) and recommends a **GO / NO-GO** decision
- Provides a **separate workspace per bid** with review / edit / approve before export
